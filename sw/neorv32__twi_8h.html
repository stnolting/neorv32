TWI control register(15) (r/-): log2(FIFO size), LSB

TWI_CTRL_FIFO_MSB 

TWI control register(18) (r/-): log2(FIFO size), MSB

TWI_CTRL_NACK 

TWI control register(23) (r/-): TX-NACK received

TWI_CTRL_NACK_CLR 

TWI control register(24) (-/w): Clear NACK flag

TWI_CTRL_IRQ_CLR 

TWI control register(25) (-/w): Clear interrupt request

TWI control register(26) (r/-): Bus is claimed by controller

TWI_CTRL_SENSE_SDA

TWI_CTRL_TX_FULL 

TWI control register(29) (r/-): TX FIFO full

TWI_CTRL_RX_AVAIL 

TWI control register(30) (r/-): RX FIFO data available

TWI_CTRL_BUSY 

TWI control register(31) (r/-): Bus engine busy or TX FIFO not empty
