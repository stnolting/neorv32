◆ NEORV32_TRACEBUF_CTRL_enum

enum NEORV32_TRACEBUF_CTRL_enum

TRACEBUF control register bits

Enumerator
TRACEBUF_CTRL_EN 

TRACEBUF control register (0) (r/w): TRACEBUF enable, reset module when 0

TRACEBUF_CTRL_HSEL 

TRACEBUF control register (1) (r/w): Hart select for tracing

TRACEBUF_CTRL_START 

TRACEBUF control register (2) (r/w): Start tracing, flag always reads as zero

TRACEBUF_CTRL_STOP 

TRACEBUF control register (3) (r/w): Manually stop tracing, flag always reads as zero

TRACEBUF_CTRL_RUN 

TRACEBUF control register (4) (r/-): Tracing in progress when set

TRACEBUF_CTRL_AVAIL 

TRACEBUF control register (5) (r/-): Trace data available when set

TRACEBUF_CTRL_IRQ_CLR 

TRACEBUF control register (6) (r/w): Clear pending interrupt when writing 1

TRACEBUF_CTRL_TBM_LSB 

TRACEBUF control register (7) (r/-): log2(trace buffer depth), LSB

TRACEBUF_CTRL_TBM_MSB 

TRACEBUF control register(10) (r/-): log2(trace buffer depth), MSB
