**Key Features**

* Compatible to the AXI-4 stream standard
* Independent RX and TX channels
* Optional per-channel FIFOs with configurable depths
* Supports "last" and "source/destination" stream signals
* Interrupt based on FIFO status


**Overview**

The stream link interface provides independent RX and TX channels/links for sending and
receiving streaming data. Each channel features a configurable internal data FIFO (depth
configurable by the `IO_SLINK_RX_FIFO` and `IO_SLINK_TX_FIFO` top generics).

.AXI4-Stream-Compatible
[NOTE]
The interface names as well as the underlying protocols are compatible to the AXI4-Stream
standard. A processor top entity with AXI4-Stream-compatible interface names can be found in
`rtl/system_integration`. More information can be found in the user guide:
https://stnolting.github.io/neorv32/ug/#_packaging_the_processor_as_vivado_ip_block

Each channel consists of the following signals:

* `dat` provides the actual data word
* `val` indicates the current transmission cycle is valid
* `rdy` indicates the receiver is ready to receive
* `lst` indicates the current transmission cycle is the last element of a stream (optional)

Data is transferred whenever `val` and `rdy` are high at the same time.

**Theory of Operation**

The SLINK provides three interface registers. The control register (`CTRL`) is used to configure the
module and to check its status. Two individual data registers (`DATA` and `DATA2`) are used to send
and receive the actual data by writing/reading data to/from the internal data FIFOs.

The `DATA` and `DATA2` registers provides direct access to the internal RX/TX FIFO buffers. Read accesses
pop data from the RX FIFO and write accesses push data to the TX FIFO. The FIFO status (empty, half-full,
full) can be checked by the according control register flags.

The "end-of-stream" delimiter is handled differently for the RX and TX channel. Writing data to `DATA2`
instead of `DATA` will automatically set the "end-of-stream" signal for the pushed data word. For the RX
channel, software can check if the oldest data word in the RX FIFO is marked as "end-of-stream" by checking
the `SLINK_CTRL_RX_LAST` control register flags (**before** reading the actual data word from `DATA`).

RX and TX channels can be enabled individually by the `SLINK_CTRL_RX_EN` and `SLINK_CTRL_TX_EN` control
register bit. Clearing an enabled bit will also flush the according data FIFO and will also terminate
any transmission being in progress.

**Interrupt**

The SLINK module provides a single interrupt request that can be used to signal certain RX/TX data
FIFO conditions. These interrupt conditions are based on the RX/TX FIFO status flags and are programmed
by the `SLINK_CTRL_RX_IRQ_SEL` (for the RX channel) and `SLINK_CTRL_TX_IRQ_SEL` (for the TX channel)
bit fields.

.SLINK RX/TX Interrupt Trigger Select (and provided bit field C-macros)
[cols="^1,^6,^6"]
[options="header",grid="all"]
|=======================
| Bit mask | RX channel | TX channel
| `00` | `SLINK_RX_IRQ_NONE` : Interrupt disabled | `SLINK_TX_IRQ_NONE` : Interrupt disabled
| `01` | `SLINK_RX_IRQ_AVAIL` : Interrupt if FIFO is not empty (data available) | `SLINK_TX_IRQ_EMPTY` : Interrupt if FIFO is empty
| `10` | `SLINK_RX_IRQ_HALF` : Interrupt if FIFO is at least half full | `SLINK_TX_IRQ_NHALF` : Interrupt if FIFO is less than half full
| `11` | `SLINK_RX_IRQ_FULL` : Interrupt if FIFO is full | `SLINK_TX_IRQ_FREE` : Interrupt if FIFO is not full (free space available)
|=======================

The SLINK interrupt fires as soon as the RX **or** TX condition is met (and the according RX/TX enable
flag is set). Software can determine the triggering condition using the `SLINK_CTRL_RX_IRQ_PEND` and
`SLINK_CTRL_TX_IRQ_PEND` flags in the control register. The interrupt remains active until all
interrupt-causing conditions are resolved (e.g. by reading data from the RX FIFO).
